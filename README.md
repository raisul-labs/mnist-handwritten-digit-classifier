# MNIST Handwritten Digit Classifier

## Project Overview
This project builds a Deep Learning model to recognize handwritten digits (0–9) using the MNIST dataset.

## Technologies Used
- Python
- TensorFlow & Keras
- NumPy
- Matplotlib
- Scikit-learn

## Model Architecture
- Input Layer
- 3 Hidden Dense Layers
- Batch Normalization
- Dropout
- Output Layer (10 Classes)

## Dataset
MNIST dataset containing 60,000 training images and 10,000 testing images.

## Features
- Image Normalization
- Data Flattening
- Deep Neural Network
- Model Training with Validation
- Accuracy and Loss Visualization
- Test Evaluation
- Confusion Matrix
